## 念念 v1.10.0 Beta 1

念念是一款极简、离线优先的 Windows 灵感记录工具。本版本为免费公测版。

### 主要功能

- `Ctrl + Shift + Space` 快速呼出
- Enter 保存、Shift + Enter 换行、Esc 关闭
- 本地 SQLite 存储，离线可用
- 历史记录、关键词搜索、标签筛选和编辑
- 系统托盘与开机启动
- 可选的个人 Supabase 多电脑同步
- 可选的 AI 整理与内容生成（自备 API Key）

### 免费公测说明

- 本版本不收费、不需要 License。
- 云同步使用用户自己的 Supabase 项目。
- AI 功能使用用户自己的 Provider 和 API Key。

### 安装方法

1. 下载 `Niannian-v1.10.0-beta.1-win64-portable.zip`。
2. 使用同页的 `SHA256SUMS.txt` 校验文件。
3. 解压到固定目录后运行 `QuickIdea.exe`。
4. 不要直接在压缩包中运行。

### Beta 注意事项

- 当前仅支持 Windows 10/11 64 位。
- 当前安装包尚未商业代码签名，Windows 可能显示 SmartScreen 提示。
- 重要内容请定期备份 `%LOCALAPPDATA%\QuickIdea`。
- 多电脑同步仍处于公测阶段，建议先用非关键数据测试。
